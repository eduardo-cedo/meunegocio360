# Projeto MeuNegocio360 - Documento de Requisitos (Frontend)

## Visão Geral: Arquitetura do Sistema

| Módulo      | Objetivo                       | Funcionalidades                                                                                                            |
| ----------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| Núcleo      | Base empresarial               | Gestão de usuários, clientes, fornecedores, produtos, serviços, vendas e contas a pagar e a receber.                       |
| Serviços    | Gestão operacional de serviços | Gestão de técnicos, equipamentos, solicitações, ordens de serviço (OS), execução, evidências, aceite e faturamento das OS. |
| Suprimentos | Estoque e compras              | Movimentações, estoque mínimo, inventário, compras, reposição, curva ABC, giro de estoque e alertas.                       |

## Frontend
- Stack utilizada: React JS com Vite
- Paleta de cores: deve ser definidos como estilos globais da aplicação.
    - Laranja: #EC4E26 (botões primarios, barra de navegação e texto de botões onHover e secundários)
    - Creme: #FCF5F0 (fundo das páginas e cartões)
    - Cinza: #4A3F39 (linha das tabelas e bordas dos cartões e texto secundário)
    - Preto: #1f1612 (texto principal)
    - Laranja amarronzado claro: #CDBBAE (rodapé)
- Fonte:
    - Barlow Condensed (pesos 500, 600 e 700): para títulos.
    - Barlow (pesos 400, 500 e 600): para textos, tabelas e rodapés.
